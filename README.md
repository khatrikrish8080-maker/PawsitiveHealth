# PawsitiveHealth
AI Vet: Pawsitive Health 🐾
Real-time Pet Health Monitoring using Computer Vision & Deep Learning
📌 Project Overview
PawsitiveHealth is an advanced Generative AI and Retrieval-Augmented Generation (RAG) application designed to assist veterinary professionals and pet owners with intelligent symptom analysis, clinical decision support, and veterinary reference queries.

🚀 Features
AI Veterinary Assistant: Powered by LangChain and state-of-the-art LLMs to interpret pet symptoms and provide structured guidance.

RAG-Powered Knowledge Retrieval: Queries specialized veterinary databases and documents to ground responses in accurate medical literature.

Streamlined Architecture: Built using modern Python modules (agent.py, app.py, rag_engine.py, and llm.py) for clean separation of concerns and high maintainability.

📂 Project Structure
app.py: Main application entry point / user interface layer.

agent.py: Core agentic workflows and orchestration logic.

rag_engine.py: Document loading, vector embedding, and retrieval pipeline.

llm.py: Model configuration and LLM initialization.
